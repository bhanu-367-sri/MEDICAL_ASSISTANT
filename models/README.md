# Specialist model weights

Place your **own trained and validated** YOLO weights here:

- `eye_yolo.pt` — eye image task
- `lung_yolo.pt` — chest X-ray task
- `fracture_yolo.pt` — bone X-ray task

The app intentionally does not include or pretend to have medical model weights. Ensure the label definitions match your dataset and describe the model's intended use in your demo. Keep patient data private.
